Zusammenfassung
CSS (Cascading Style Sheets) ist die Sprache, die das Aussehen von Webseiten bestimmt. Zusammen mit HTML und JavaScript bildet CSS eine der drei Grundlagentechnologien des World Wide Web. In diesem Dokument lernst Du, wie Du mit CSS Farben, Schriftarten, Layouts und Abstände steuern kannst. Du wirst verstehen, wie Selektoren funktionieren, wie Du Farben auf verschiedene Weisen angeben kannst und wie externe Stylesheets dazu beitragen, Webseiten konsistent und wartbar zu gestalten.
